# Nsda-Registration-Form Validation Project
A fully interactive, client-side validated form with real-time validation and dynamic user feedback.

## 🌐 Live Demo

[**View Live Project**](https://nsda-practice-registration-form.netlify.app/)

## ✨ Features

### ✅ Real-Time Validation
- Instant feedback for all form fields
- No page reloads required
- Continuous validation during user input

### 📝 Field Validation Includes:
- **Name Field**: Minimum length and character validation
- **Email Field**: Format validation with regex pattern matching
- **Phone Number**: Number format and length validation
- **Password**: Strength requirements with visual feedback

### 🔧 Advanced Features
- **Dynamic Error Messages**: Contextual messages appear next to invalid fields
- **Password Strength Meter**: Visual indicator showing password security level
- **Interactive UI**: Smooth transitions and focus effects
- **Field Event Handling**: Comprehensive focus, blur, and input event management
- **Professional Styling**: Modern, clean design with responsive layout

## 🚀 Technologies Used

- **HTML5**: Semantic markup and form structure
- **CSS3**: Modern styling with Flexbox, transitions, and responsive design
- **JavaScript (ES6)**: Client-side validation logic and DOM manipulation
